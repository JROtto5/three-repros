three.js #34697: WebGPU timestamp queries of resumed / layered render passes

Renders one frame with WebGPURenderer({ trackTimestamp: true }) using three.js and records the timestampWrites of every render pass the renderer begins. A pass that is resumed (after a framebuffer copy) or a later layer should only write the end timestamp of its render context. The bug: it writes the beginning timestamp again, or the indices of another pass.

Cases: split by copy · nested reflector() · shadow pass · layered (ArrayCamera) · no split
